# Templates — one per method family

A result section has a shape that depends on what was measured. A communication network, a
differential-expression table and a trajectory are described differently, claim different things,
and carry different caveats — and a writer handed only the general instruction writes the same
paragraph for all three.

So the general skill carries the RULES and a template carries the METHOD. Pick the template whose
method family matches the plugin the run used; if none matches, write from the general skill and
then **add a template**, because the next person will meet the same method.

## What a template must contain, and why each part

| section | why it is required |
|---|---|
| **What the method infers** | The single sentence a reader needs before any finding means anything. Most misreadings of a section are a misreading of this. |
| **What a result of this kind supports** | The claims the measurement licenses. Written as permissions, so an author knows what they may say. |
| **What it does NOT support** | The claims it does not, each with the reason. This is not defensive writing — it is the boundary that makes everything inside it sayable. |
| **The order to write in** | Method families have a natural order of exposition. Getting it wrong is the commonest structural fault. |
| **Caveats to attach, with citations** | Named, cited, and attached ONCE where they belong — not repeated under every finding. |
| **Sentence patterns** | Filled from the run's own numbers. Patterns, not prose to copy: a template that produces identical paragraphs across studies is a template nobody should use. |

## Rules that apply to every template

- **The numbers are the run's.** A template shapes sentences; it never supplies a value.
- **A caveat is stated once**, where it belongs — a property of the run at the top, a property of
  one contrast in that contrast. A constant repeated under every finding buries the findings.
- **A hypothesis is legible as one.** Templates may and should carry interpretive sentence
  patterns; they mark them as interpretation in the grammar.
- **A template is not a cage.** If the run measured something the template has no pattern for,
  write the sentence and add the pattern.

## The templates

- `cell-cell-communication.md` — ligand–receptor network inference between populations
  (CellChat, LIANA, CellPhoneDB, NicheNet and the like)

Add one by copying the section list above and filling it for the method family. A template that
names a specific study, tissue or cohort is wrong: templates travel, studies do not.
